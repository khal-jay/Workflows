---
name: ui-polish
description: Polish the UI with Designer review and QA validation
---
1. Activate `product-designer` to review the current UI implementation against the design system and "WOW" standards.
2. The Designer will implement micro-interactions or CSS refinements.
3. Once polished, activate `qa-engineer` to validate the visual fidelity and accessibility (WCAG) on mobile and desktop.
4. Final approval from `product-manager` before closing the task.
