---
name: start-feature
description: Begin a new feature with PM scoping and Architect design
---
1. Activate `product-manager` to define the feature scope, North Star, and success metrics.
2. Once the PM spec is approved, activate `system-architect` to design the API, database schema, and security boundaries.
3. Once the architectural spec is verified, activate `orchestrator` to route implementation tasks to the engineering division.
